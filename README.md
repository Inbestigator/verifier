# Verifier

This is a bot made with [Dressed](https://dressed.js.org) using [@dressed/framework](https://npmjs.com/@dressed/framework) and [@dressed/react](https://npmjs.com/@dressed/react) which will show captchas to new users.

You can check out
[the GitHub repository](https://github.com/inbestigator/dressed) - your feedback
and contributions are welcome!
